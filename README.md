# SkillRoute 🚀

> **Know what to learn. Know what's next.**

SkillRoute is a student-focused career skill-planning startup concept for the BridgeAura final assignment. It helps students turn a career goal and personal profile into a clearer route of skills, projects and next steps.

## Core flow
**Career Goal → Student Profile → Skill Assessment → Skill-Gap Analysis → Personalized Roadmap → Progress → Reassessment**

## AI/Data prototype
The working prototype uses a transparent, deterministic role–skill dataset to calculate skill gaps from a student's self-rated confidence. It is intentionally auditable for the assignment; a production version could add an LLM after retrieval to explain grounded recommendations.
