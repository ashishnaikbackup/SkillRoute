# SkillRoute 🚀

> **Know what to learn. Know what's next.**

SkillRoute is a student-focused career skill-planning platform developed as the **BridgeAura internship startup assignment**. It helps students turn a career goal and their current profile into a clearer, personalized path of skills, projects and next steps.

---

## 🎯 Project Overview

Students often know the career they want, but struggle to understand:

- Which skills are actually required for the target role
- Which skills they already have
- Where their skill gaps are
- What they should learn first
- Which projects can help them gain practical experience
- How their roadmap should change as they improve

**SkillRoute** addresses this by connecting career goals, student profiles, skill assessment, AI-assisted gap analysis, personalized roadmaps and progress reassessment in one continuous workflow.

### Core flow

**Career Goal → Student Profile → Skill Assessment → Skill-Gap Analysis → Personalized Roadmap → Progress → Reassessment**

# 💡 Problem

Career guidance for students is often fragmented. Students can find thousands of courses and roadmaps, but still lack a clear answer to a simple question:

> **“What should I work on next?”**

Generic roadmaps also fail to account for the student's current skills, projects, experience and progress.

---

# 💙 Solution

SkillRoute creates a personalized career skill route based on:

- Target career / role
- Education and background
- Current technical and soft skills
- Projects and practical experience
- Skill confidence / assessment
- Identified skill gaps
- Progress over time

The system then prioritizes the next skills and practical actions instead of simply giving the student another long list of resources.

---

# 👥 Target Users

### Primary users

- College students
- Engineering students
- Students preparing for internships
- Students preparing for placements
- Beginners entering a new technical career path

### Example

A student selects **Frontend Developer** as their target role. SkillRoute can identify the relevant skills, compare them with the student's current profile, highlight gaps such as React or API integration, and create a prioritized route for improvement.

---

# ⭐ Core Features

### 1. Career Goal Selection
Choose the role or career direction the student wants to pursue.

### 2. Student Skill Profile
Capture education, skills, projects, experience and current confidence.

### 3. Skill Assessment
Understand the student's current capability instead of assuming everyone starts from the same point.

### 4. AI-Assisted Skill-Gap Analysis
Identify important missing or developing skills and explain why they matter for the target role.

### 5. Personalized Roadmap
Turn identified gaps into an ordered sequence of learning priorities and practical projects.

### 6. Progress Tracking
Track completed skills, learning milestones and project progress.

### 7. Reassessment
As the student's profile improves, reassess the gaps and update the roadmap.

# 🤖 AI / Data Direction

The product concept uses AI to support:

1. Skill-gap identification
2. Explanation of why a skill matters
3. Prioritization of learning goals
4. Personalized learning/project recommendations
5. Roadmap updates after reassessment

The AI layer is intended to support the student's decision-making rather than simply generate another generic course list.
