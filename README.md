# SkillRoute 🚀

> **Know what to learn. Know what's next.**

SkillRoute is a student-focused career skill-planning startup concept for the BridgeAura final assignment. It helps students turn a career goal and personal profile into a clearer route of skills, projects and next steps.

## Core flow
**Career Goal → Student Profile → Skill Assessment → Skill-Gap Analysis → Personalized Roadmap → Progress → Reassessment**

## Product
SkillRoute starts with a career goal and student profile, compares the profile with structured role/skill requirements, identifies priority gaps, recommends a sequence of learning + projects, and updates the route through reassessment.

## Business model
Free acquisition → **₹149/month Pro** → **₹60/student/year Campus** → **₹499 Career Packs**.

These figures are proposed assumptions for the assignment model, not audited market claims.
