# SkillRoute — Dataset & Sources

## Purpose
This package supports the BridgeAura Dataset & Sources deliverable and the SkillRoute AI/data strategy.

## Demo dataset
`SkillRoute_Dataset_Role_Skill_Demo.csv` is a small synthetic role–skill dataset created specifically for the working prototype. It is not presented as scraped proprietary job data.

Fields: role, skill, target_level (1–5), priority, why_it_matters.

## External reference sources
- ESCO — European Skills, Competences, Qualifications and Occupations (European Commission): https://esco.ec.europa.eu/
- O*NET Web Services / O*NET Database: https://services.onetcenter.org/
- National Career Service, Government of India: https://www.ncs.gov.in/
- National Classification of Occupations (NCO) 2015: https://www.ncs.gov.in/documents/national%20classification%20of%20occupations%20_vol%20i-%202015.pdf

## Intended use
SkillRoute combines a student's target career and self-assessed skills with the role–skill mapping to calculate gaps and prioritize next actions. A production version would expand, validate and version this knowledge base and retain source/version metadata.

## Privacy
The prototype uses synthetic student data only. No real personal, financial, medical, identity or credential data is included.
